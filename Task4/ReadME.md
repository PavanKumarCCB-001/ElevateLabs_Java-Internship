# 📝 Notes App (Java Console)
A simple CLI-based Notes App built in Java for my Java Developer Internship at Elevate Labs.

## ✅ Features:

- Read data from a file
- Write data to a file (append mode)
- Delete a file
- Handles file not found and I/O exceptions gracefully

## ▶️ Execution

```
javac Notes.java

java Notes
