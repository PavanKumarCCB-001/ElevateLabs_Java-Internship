# ✅ ToDo App (Java Swing GUI)
A simple desktop ToDo App built with Java Swing for my Java Developer Internship at Elevate Labs.

## ✅ Features:

- Add tasks from the text field
- Delete a selected task from the list
- Press Enter to add a task quickly
- Scrollable task list
- Ignores empty input
- Fixed-size window with a clean header layout

## ▶️ Execution

From the internship root folder:

```
javac Task6/TodoApp.java

java Task6.TodoApp
```

From the `Task6` folder:

```
javac TodoApp.java

java -cp .. Task6.TodoApp
```
