# 🧮 Calculator  (Java Console)
A simple CLI calculator built in Java for Day 1 of my Java Developer Internship at Elevate Labs.

## ✅ Features:

Basic operations: ``` + ``` , ```-``` , ```*``` , ```/```

Repeats until user exits

Handles divide-by-zero using exception handling

## ▶️ Execution

```
javac Calculator.java

java Calculator
```
