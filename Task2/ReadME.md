# 📚 Student Record Management System (Java Console)
A simple CLI-based Student Record Management System built in Java for my Java Developer Internship at Elevate Labs.

## ✅ Features:

- Add student details (ID, Name, Marks)
- View all student records
- Update existing student details
- Delete student records
- Handles invalid inputs and ensures data integrity

## ▶️ Execution

```
javac Crud.java

java Crud
